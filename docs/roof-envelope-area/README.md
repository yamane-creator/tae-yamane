# 屋根外皮面積の照合・再計算記録

記録日：2026年10月8日。添付図面とチャットでの計算・修正内容を整理した記録。

## 確認結果

外皮性能図1のU値計算表の屋根面積は **94.764㎡**、外皮性能図7の屋根外皮面積は **94.045㎡**。差は **0.719㎡**。

図7はR-1～R-5・R-8を3.65寸勾配で計算している。一方、立面図・断面詳細図には4寸勾配が記載されている。R-6・R-7・R-9は1.5寸勾配であり、最終の再計算では変更しない。

図7の面積欄から3.65寸部分の合計61.265㎡を4寸に換算すると、61.265×√(1＋0.4²)÷√(1＋0.365²)＋32.780＝94.764536…㎡。今回の差は主に勾配設定の違いで説明できる。ただし、この値を小数第4位で四捨五入すると94.765㎡となり、94.764㎡とは厳密には一致しない。図1が4寸を使っていることも元データでの確認は未実施。

## 最終の修正表

図7に記載された寸法から再計算。R-6・R-7・R-9は1.5寸を維持し、ほかは4寸。各面積は小数第4位を四捨五入し、小数第3位まで表示。

| 部位 | 計算式 | 面積（㎡） |
|---|---|---:|
| R-1 | 3.640×5.915×√(4×4＋100)÷10 | 23.189 |
| R-2 | (2.730＋3.640)×0.151÷2×√(4×4＋100)÷10 | 0.518 |
| R-3 | 1.061×2.730×√(4×4＋100)÷10 | 3.120 |
| R-4 | (2.730＋2.886)×0.455÷2×√(4×4＋100)÷10 | 1.376 |
| R-5 | (2.886＋3.848)×0.151÷2×√(4×4＋100)÷10 | 0.548 |
| R-6 | (5.611＋7.014)×0.455÷2×√(1.5×1.5＋100)÷10 | 2.904 |
| R-7 | (7.583＋12.891)×1.820÷2×√(1.5×1.5＋100)÷10 | 18.840 |
| R-8 | (7.852＋9.100)×3.640÷2×√(4×4＋100)÷10 | 33.229 |
| R-9 | (1.478＋8.114)×2.275÷2×√(1.5×1.5＋100)÷10 | 11.033 |
| **再計算合計** | | **94.757** |
| **図1の採用値（再計算合計と別）** | | **94.764** |

端数処理前の合計は94.756820838…㎡。表示値との差は0.007㎡だが、処理前では94.764－94.756820838…＝0.007179162…㎡。94.764㎡は記載寸法から求まった計算結果ではない。

## 端数処理・勾配変更の比較

| 条件 | 合計（㎡） |
|---|---:|
| 4寸・1.5寸を使い分け、各部位で小数第4位を四捨五入 | 94.757 |
| 同条件で、端数処理前の合計を小数第4位で四捨五入 | 94.757 |
| 同条件で、各部位の小数第4位以下を切り捨て | 94.752 |
| 同条件で、端数処理前の合計の小数第4位以下を切り捨て | 94.756 |
| 同条件で、各部位の小数第3位を四捨五入 | 94.76 |
| R-1～R-9をすべて4寸に変更し、小数第4位を四捨五入 | 96.891 |

小数第2位まで表示すれば94.764㎡も94.76㎡になるが、表示が一致するだけで元の計算値の差は解消しない。全箇所を4寸とする案は、その後のユーザー訂正により最終案から除外。

## 残差の確認が必要な理由

元の図7には、記載式と面積欄が一致しない箇所がある。

| 部位 | 記載式から再計算（小数第4位を四捨五入）（㎡） | 図7の面積欄（㎡） |
|---|---:|---:|
| R-2 | 0.512 | 0.514 |
| R-5 | 0.541 | 0.544 |
| R-6 | 2.904 | 2.905 |
| R-7 | 18.840 | 18.841 |
| R-9 | 11.033 | 11.034 |

上記は元の3.65寸・1.5寸で比較。表示より細かい寸法を使っている可能性、転記や更新漏れの可能性があるが、添付PDFだけでは確定できない。通常の面積の四捨五入だけでは説明できない箇所があるため、元の計算データを確認する必要がある。
