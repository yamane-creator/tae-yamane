## その他の表記差と確認事項

- 1階・2階とも、正図の「いb・ろa・ろb・はa・はb」等のa／b区別は、0512図では省略されている。大分類の一致だけで商品仕様の一致とは判断できない。
- 正図には金物記号と商品型番の対応表がないため、商品同等性・必要耐力は未判定。
- 0512図のNo.1・2の柱脚はHi43×2、No.3～6の柱脚はHi28。No.7は柱脚記号・商品表示が空欄。
- 0512図の2階には、Z両引きボルトL800（り6・を6・わ6・わ8）、高耐力両引きボルトL850（り2・り3）、偏心座金付きボルトⅡ L550（り5右側・右上丸囲み柱の左側）の追記がある。正図には同じボルト注記はない。
- ボルト追記は上下階接合の納まりに関わるため、記号修正時に機械的に削除せず、設計者へ確認する。
- 2図は通り芯名称が一部異なるため、対応は寸法・部屋位置と図面上の並びで照合した。相違番号は比較PDF・CSVと共通。

本資料は添付2図の表記比較。原図の指定を変更した施工図ではない。施工状態・取付方向・構造計算の妥当性は確認対象に含まない。
