# 森田厚史様邸 構造図まとめ

作成日：2026年10月8日。

[まとめた構造図PDF](森田厚史様邸_構造図まとめ.pdf)

添付の「261006構造図まとめ.zip」に含まれるJWW図面全47件を、図面番号順に1図面1ページでPDF化しました。S03の通常版と「＋」版を両方含みます。全47ページ、A3横向き。各図面名のしおりを付けています。

Jw_cad本体からの印刷ではなく、ezjww 0.5.0でDXF変換し、ezdxf 1.4.4でPDFに描画しています。元のJWWファイルは変更していません。
日本語フォントはNoto Sans Mono CJK JPに代替したため、Jw_cadでの印刷とは文字の形や配置が異なる場合があります。白地・黒線で出力し、非表示レイヤと印刷対象外の補助線は描画していません。

JWW全47件の読み取り、未対応要素・未解決ブロック参照・文字の置換エラーがないこと、全PDFページの描画を確認しました。代表ページの図面枠・日本語表記も目視確認済みです。Jw_cadからの正式な印刷結果との全要素照合は未実施です。
