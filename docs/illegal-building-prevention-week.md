# 違反建築防止週間：琴浦町での確認用メモ

記録日：2026年10月8日。
対象地域：鳥取県東伯郡琴浦町。
対象年度：令和8年度（2026年4月1日〜2027年3月31日）。

## 全国的な期間の目安と確認状況

チャットでは、例年の「違反建築防止週間」の目安として **10月15日〜21日** と案内した。
ただし、今回の調査では公式資料を取得できておらず、この期間の根拠となる公表資料との照合は未完了。
**確認済みの実施日程として扱わないこと。**

2026年度の全国の実施案内、および琴浦町を対象とするパトロールの実施日は未確認。
週間の期間と、実際に現場を巡回する日は区別して確認する必要がある。
パトロールや違反の調査がこの期間だけに限られると判断しないこと。

## 日程を確認する際の問い合わせ

問い合わせ先の候補は、鳥取県中部総合事務所の建築指導担当。
現在の正式な担当課名・連絡先・琴浦町の担当窓口は未確認のため、県または町の公式案内で確認する。

問い合わせ文例：

> 令和8年度の一斉違反建築パトロールで、琴浦町を巡回する日はいつですか？
