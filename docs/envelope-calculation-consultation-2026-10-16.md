## 2. 2026年10月の外皮性能計算の変更

**質問：** 外皮性能計算が10月から新しくなったが、以前と何が違うか。

**回答の要旨：**

2026年10月の改定として説明し、次の二つを分けて整理しました。

### 10月1日の窓・日射の評価方法の更新

- ガラス仕様・付属部材による日射熱取得率について住宅と非住宅の評価内容を統一。
- 日射制御を目的とした付属部材について、冷房期と暖房期で切り替えて評価できる方法に変更。
- ダブルスキン・エアフローウィンドウを住宅の評価対象に追加。
- 傾斜した庇の記載整理は、当該変更前後で評価結果を変えないもの。

「夏は外付けブラインドで遮り、冬は開放して日射を取り込む」使い方を季節別に評価する考え方を説明しました。対象部材の開閉条件等と、ソフトの対応確認が必要です。

### 10月末の基礎の旧評価方法の経過措置終了

土間床等の外周部と基礎壁の熱損失を一体として扱う旧評価方法（技術情報の付録D）の適用期限は2026年10月31日まで、と説明しました。

これは10月1日の窓まわりの変更とは別件です。計算方法の変更によって、同一仕様でも数値が変わる場合があり、「新しくなると必ず悪化する」とは判断できません。

- [建築研究所・日射熱取得率（2026年10月版・変更履歴付き）](https://www.kenken.go.jp/becc/documents/house/3-4_261001_v21_rireki.pdf)

## 3. ARCHITRENDでの外付けブラインド設定

**質問：** 「夏は外付けブラインドで遮り、冬は開放する」設計はどこで設定するか。

**公式公開ヘルプで確認した従来の操作：**

1. 外皮性能計算で対象の「熱的境界（建具）」の属性変更を開く。
2. 「ガラス」欄の「仕様」「装飾」「日射熱取得率」を確認する。
3. 平面図の建具属性にある「日射遮蔽措置：外付けブラインド」は、自動配置時に熱的境界（建具）の「装飾」に連携する。

**未確認事項：**

- 2026年10月改定に対応した冷房期／暖房期別の具体的な設定画面。
- その機能が使えるARCHITRENDのバージョン・ビルド番号。
- ユーザー環境での実際の入力欄と出力結果。

前の回答では制度上の季節別評価を先に説明していましたが、ARCHITRENDでの対応は確認できていないことを、その後の回答で訂正しました。「装飾：外付けブラインド」とするだけで冬が開放評価になるとは確認できていません。

**参照：**

- [福井コンピュータ公式FAQ：熱的境界（建具）のガラスの日射熱取得率を変更する方法（Ver.9・2022年更新）](https://www.fukuicompu.co.jp/mnl/ZERO/Ver9/bfaq/Content/Q560_gsk/Q560130_gla.htm)

## 4. LIXIL EWの窓仕様と外付けブラインドの数値

**質問：** LIXILの引違い窓の場合、外付けブラインドの数値はどこで確認できるか。

確認先として、LIXILの「ガラス・建具ごとの日射熱取得率」の表を案内しました。窓種だけで決まる値ではなく、サッシ材質・ガラス仕様・付属部材の組み合わせで確認します。

**ユーザーが示した窓仕様：**

- EW
- 引違い窓
- トリプルガラス
- アルゴンガス入り
- グリーン×グリーン

### 規定値で評価する場合の整理

LIXILの分類表ではグリーン×グリーンはダブルLow-E三層複層ガラスの日射遮蔽型に該当します。EWは樹脂製建具として確認します。

建築研究所の2026年10月版・付録C・表2(a)で確認した窓全体の日射熱取得率の規定値は、次のとおりです。

| 評価状態 | 窓全体の日射熱取得率η |
|---|---:|
| 外付けブラインドあり | 0.06 |
| 付属部材なし | 0.24 |

- 夏にブラインドあり、冬に開放して付属部材なしとして評価する場合の規定値として説明しました。
- 開閉可能な対象部材であることなど、季節別評価の条件確認が必要です。
- これはガラス単体のη値ではありません。ARCHITRENDの入力欄が何の値を求めているかを確認する必要があります。
- 規定値による評価と、製品別の試験値・計算値を用いる評価は区別します。製品別の値から根拠なく0.06へ変更することは避けます。

**参照：**

- [建築研究所・2026年10月版 PDF17ページ・表2(a)](https://www.kenken.go.jp/becc/documents/house/3-4_261001_v21_rireki.pdf#page=17)
- [LIXIL・ガラス／建具ごとの日射熱取得率](https://www.biz-lixil.com/service/law/energy-saving/pdf/windows_doors/crust_03A.pdf)

### 「LIXILの分類表が古い。最新版はあるか」への回答

2026年10月16日に公式掲載先を確認した範囲では、外付けブラインド列を持つ上記分類表は2024年11月1日改訂版のままで、それより新しい同形式の表は見つかりませんでした。

一方、次の新しい別資料があります。

| 資料 | 確認した改訂日・用途 |
|---|---|
| ガラス・建具ごとの日射熱取得率 crust_03A | 2024年11月1日。ガラス分類・付属部材込みの規定値 |
| EW引違い用 RWG359 | 2026年5月1日。2025年4月発売品・樹脂スペーサー仕様の製品別性能 |
| ガラス性能一覧 LXEC-1309附属書 | PDF記載は2026年6月1日。ガラス単体の詳細性能 |

RWG359には「本表使用の場合は和障子及び外付けブラインド取付け時も同じ値」との注記があります。この製品別表と、付属部材込みの規定値の表を混同しないように整理しました。

## 5. 提供基礎図面と、熱橋に関する相談

**質問：** 基礎伏図で基礎断熱部分の平均熱貫流率を計算する場合、熱橋部分はあるか。

このチャットで提供された基礎伏図（断熱入り）1枚と、追加の基礎伏図・基礎詳細図2枚を確認しました。

### 図面から確認した事項

- 最初の図面の斜線が断熱材の施工範囲。
- 断熱材の記載：押出法ポリスチレンフォーム3種b・厚50mm。
- 外周に帯状の断熱範囲が示されている。
- 基礎断面FG1：コンクリート幅150mm、GL上の立ち上がり400mm。
- FG3には内部立ち上がりがある。
- FG4・FG5は地中梁の断面として示されている。
- 追加の基礎詳細図自体には、断熱材の施工断面は描かれていない。

### ユーザーからの補足

1. 「断熱材は前回送った図面の斜線部分」
2. 「立上りの厚みは100㎜」
3. 「底盤の上に敷き、外周立ち上がりの内側にも張る納まり」

**100mmの解釈について：**

直前の回答では、ユーザーの「立上りの厚み100mm」を「立ち上がり内側の断熱材の厚さ100mm」と解釈し、断面図のコンクリート厚150mmとは区別しました。ただし、断熱材厚であることをユーザーが明示的に言い直した段階ではありません。コンクリート厚を指す場合は図面の150mmと不一致になるため、計算仕様の確定前に確認が必要です。

### 最後に整理した計算上の考え方

**基礎壁の一般部分のU値と、取り合い部の熱橋を分けて扱う。**

| 対象 | この相談での整理 |
|---|---|
| コンクリート基礎壁に断熱材を連続して張る一般部分 | 一般部100％・熱橋部0％として層構成からU値を求める考え方 |
| 内部基礎梁の平面面積 | 存在するだけで基礎壁U値の熱橋面積比率に加算しない |
| 鉄筋 | 木造の柱・間柱のような別の面積比率として入力しない |
| 外周基礎と内部立ち上がりFG3の接続部 | 内側断熱が途切れる場合は物理的な熱橋になり得る。接続部の断熱折り返し等は未確認 |
| 底盤上の水平断熱50mm | 外周立ち上がり壁のU値にそのまま加えず、採用する土間床等外周部の評価方法で扱う |
| 基礎壁のU値と土間床等外周部のψ | 別々に評価する方式を前提に整理 |

直前の回答で提示した、一般部分の暫定層構成：

| 材料 | 厚さ |
|---|---:|
| 基礎コンクリート | 150mm（基礎断面図による） |
| 内側断熱材 | 100mm（ユーザーの説明を断熱材厚と解釈） |

「一般部100％・熱橋部0％」は、断熱材が連続している一般断面についての整理です。建物全体に熱橋がない、あるいはFG3等の取り合い部の評価が確定したという意味ではありません。

初期の回答では「実際の熱の逃げ道」と「ARCHITRENDの熱橋面積比率への入力」を混在させたため、その後の回答で区別し直しました。内部基礎があることだけを理由に熱橋比率を追加する、という結論にはしていません。

### 未実施・未確認

- 基礎壁U値の数値計算は未実施。
- 断熱材の具体的商品名・設計用熱伝導率、表面熱抵抗等の採用値は未確定。
- 100mmが断熱材の厚さを指すかの最終確認。
- 外周基礎と内部立ち上がりの接続部での断熱連続性・折り返し寸法。
- 土間床等外周部ψの採用方法・数値と、基礎壁の高さ／面積の確定。
- ARCHITRENDの実画面での設定・計算書の検証。

## 6. 続けて確認するときの順序

1. ARCHITRENDのバージョン・ビルド番号と季節別の日射遮蔽評価への対応。
2. 窓のη値入力欄が「ガラス単体」か「開口部全体」か、規定値か製品別値か。
3. 基礎立ち上がりの100mmが断熱材厚であること。
4. 内部基礎との接続部の断熱納まり。
5. 材料の設計用熱伝導率・面積・高さを確定し、U値およびψを計算。
