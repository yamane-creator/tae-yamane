# 説明内容と確認事項

2026年10月27日の説明会録音と抜粋資料に基づく補足記録です。印刷・説明用の要約は同フォルダのA4版PDFを参照してください。

## 制度の概要

鳥取県民が省エネ家電を購入する際、登録販売店が支援額を値引きし、後から事務局へ交付金を申請する制度です。値引き分は入金まで販売店が立て替えます。

| 項目 | 説明会での内容 |
| --- | --- |
| 対象者と設置先 | 県内の住宅に居住する方が、県内の自分の居住用住宅に設置する購入 |
| 対象家電 | 新品のエアコン、冷蔵庫・冷凍庫。統一省エネラベルの多段階評価が星3以上 |
| 対象外の例 | 法人事務所用、大家さんが賃貸住宅に設置する目的の購入 |
| 販売期間 | 2026年10月31日〜2027年1月31日。ただし店舗登録完了後の販売が対象。予算上限到達時は早期終了 |
| 対象経費 | 本体・配送料・取付工事費の税抜額 |
| 支援額 | 対象経費の2分の1まで。千円未満切捨て。製品・性能・サイズ・販売店区分別の1台当たり上限も適用 |
| 台数 | 1世帯あたりエアコン6台まで、冷蔵庫・冷凍庫は合わせて2台まで |
| 購入回数 | エアコンと冷蔵庫・冷凍庫の各区分で1回限り。両区分を別の日に購入することは可 |

## 販売店登録

- 受付：2026年10月29日10時〜12月28日。
- 対象：鳥取県内に実店舗があり、対象家電を販売する店舗。
- 原則オンライン申請。難しい場合はメール等で対応。FAX不可。
- 本店が県内なら「地域協力店」、県外なら「通常店」。区分により支援額が異なる。
- 主な入力事項：店舗情報、担当者情報、口座情報等。
- 主な添付書類：通帳の写し等の口座確認書類、本店所在地を確認する登記簿等。
- 個人事業主は確定申告書・開業届の写し等でも所在地を確認する扱い。法人の納税証明書で代用できるとの説明もある。
- LED照明器具買換え事業の登録店は一部入力や口座書類を省略できるが、今回の登録と本店確認書類の提出は必要。
- 審査は通常4営業日程度。承認メールは届かないためマイページで結果を確認する。
- 登録後の販促物はチラシ40枚、A1ポスター1枚、のぼり2枚。ポールは店舗で準備し、のぼりに店舗区分を記入する。

## 販売から入金まで

販売店登録 → 仮予約申請・審査 → 承認後に値引き販売 → 交付金申請 → 審査後に入金。

販売店登録・仮予約・交付金の3段階の申請があります。仮予約の審査は当面10日程度を見込む説明です。

| 段階 | 主な書類 |
| --- | --- |
| 仮予約 | 見積書等、住所記載の本人確認書類、販売店と購入者双方が署名した共同事業実施規約 |
| 交付金申請 | 交付金申請書兼実績報告書、値引き後の販売額がわかる領収書等、購入時の保証書等 |

見積書と領収書等を対にして残し、元の価格と値引き後の販売額を確認できるようにします。質疑では値引き販売の実態が確認できれば納品書でも可と説明されました。共同事業実施規約だけで見積書等の代わりにはなりません。

配送先住所は配送伝票の控え等で確認します。購入のみで配送書類がない場合は共同事業実施規約書に設置先を記載する扱いです。

## 工事と暫定申請の注意

- 工事費は申請時点で確定。申請後の追加工事に対する支援額の追加交付はできず、追加分は購入者負担となる。
- エアコンは期間内に設置が終わらなくても、機器購入のみで対象となる扱いがある。県内住宅への設置意思を書面確認し、工事費を含める場合は金額のわかる契約書等を用意する。
- 新築向けは現在の居住地も確認する。現在県内に居住し県内の建築中の自宅に設置することが確認できる場合は対象となる扱い。現在県外に居住し、まだ居住していない県内の建築中住宅向けに購入する場合は対象外。
- 仮予約フォームは11月13日開設予定。それまでは暫定メール申請。メール申請を使ってもフォーム開設後に同内容の再入力・書類登録が必要。
- 11月10日までのメール申請分を先着順に審査する予定とされる。実際の切替日と直前の受付休止日は正式告知を確認する。
- 個人情報を含む添付書類には指定のパスワードを設定。指定内容は登録後のマイページで確認する。

## 正式案内で確認すること

| 項目 | 理由 |
| --- | --- |
| 交付金の入金日程 | 口頭では毎月15日・月末締め、翌月5日・20日振込予定、締めから約3週間。抜粋FAQの5日・20日締め・約2週間と異なる。休日・年末年始等で変動するため事務局に確認 |
| 税処理とレジ対応 | 算定基準は税抜。質疑では税込値引きも可とされた一方、税相当部分を購入者から回収できない旨の説明があるため、実際の処理と販売店負担を経理・事務局と確認 |
| 保証書の提出方法 | レシートを保証書代わりとする店舗の提出方法などはその場で回答が確定せず、後日Q&A案内とされた |
| 機種別上限額 | 縮小画像のため全数値の確実な判読ができない。正式な上限額表で見積を照合 |
| 最終申請期限等 | 交付金申請の最終締切、フォーム開設日、受付休止の最新告知を確認 |
