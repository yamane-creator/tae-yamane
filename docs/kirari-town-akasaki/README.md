## 概要

環境と共生する住宅団地の住みよい環境づくりを目的とした憲章。
住宅計画では建築基準法、住宅金融公庫建設基準、その他の法令等に加え、憲章の趣旨を理解するよう求めている。
以下は本文1・2ページの要約であり、具体的な計画では原本を確認すること。

## 建物・敷地・外構の主な条件

| 項目 | 内容 |
|---|---|
| 用途 | 原則として専用住宅。配置、間取り、窓、屋根（雪持等）に配慮する |
| 店舗併用住宅 | 本文の「公社」が許可したものに限る。店舗部分は建物延べ床面積の2分の1以内。業種の制限あり |
| 建設戸数 | 同一宅地内に独立した2以上の建物は不可。ただし車庫・物置等を除く |
| 道路側の外壁後退 | 住宅の外壁面を道路境界線から1.0m以上後退させる |
| 隣地側の外壁後退 | 住宅の外壁面を隣地境界線から1.5m以上後退させる |
| 北側隣地への配慮 | 積雪・隣地採光などに関し、建て方・屋根形状等に特に配慮。配慮が困難な場合は隣地境界線から2.0m以上 |
| 最高高さ | 10m |
| 屋根・外壁の色彩 | できる限り落ち着いた色彩を基調とし、周辺環境と調和させる |
| 地盤高 | 造成地盤高は変更不可。ただし構造物の築造に伴う残土の宅地内敷き均し程度を除く |
| 車両の出入り | 歩道のある幹線道路（県道船上山赤碕線）・準幹線道路（町道桜ケ丘上野線）から宅地への車両出入りは不可 |
| 境界の施工 | 土・雨水が道路や隣地へ流れ込まないよう土留処理。構造物の天端は宅地地盤から30cm以下 |
| 囲障 | なるべく生垣や開放的なフェンス等。基礎部分の構造物は宅地地盤から30cm以下 |
| 植樹 | 環境整備と植樹の維持管理に努める |
| 汚水 | 宅地内の既設汚水桝へ接続 |
| 雨水 | 雨水桝を設置し、道路側溝へ接続 |
| 車庫等 | 周囲と調和し、積雪等で隣地に支障が生じない配置・形状・構造とする |
| 広告看板・広告塔・自動販売機等 | 住居地域内への設置は、事前に公社へ申請し、許可後に設置 |

店舗併用住宅の業種制限は本文の列挙と用途地域に関する記述を原文で確認すること。
悪臭・騒音などで周辺住民に悪影響を与えると予想される業種も許可しないと記載されている。

## 環境共生の推奨事項

- 高気密・高断熱化、日照・風を利用した住戸設計などの省エネルギー化。
- ソーラーシステムなどの自然エネルギーの活用。
- 再生・再利用しやすい部材やコンポストシステムなどによる廃棄物削減。
- 雨水や風呂の残湯の利用など、資源の有効利用。
- 節水・節電型設備機器などの活用。
