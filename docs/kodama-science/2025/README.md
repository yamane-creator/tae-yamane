抽出元のDocuWorksファイル名とZIP内の保存先は[抽出元一覧.csv](抽出元一覧.csv)に記録しています。保存フォルダーの日付とFAX受信日が異なる文書があります。複数のフォルダーに存在する同一文書は重複掲載していません。

PDFはFAX画像を原文書の用紙寸法に合わせて配置したものです。内容の書き換えや、OCR結果による文字の置き換えはしていません。OCRは候補検索に使用し、抽出した4件の表題・発行会社・日付は画像でも確認しました。

同社の請求書関連FAXおよび年末年始休業案内は対象から除外しています。

調査範囲：DocuWorks実文書3,023ファイル、内容の重複を除いた1,083文書。全ファイルから画像を抽出でき、重複をまとめた1,367ページの上部を日本語OCRで検索しました。会社名・連絡票の表題・FAX番号の候補を確認しました。画像による検索のため、文字が判読しづらい場合の見落としの可能性はあります。
